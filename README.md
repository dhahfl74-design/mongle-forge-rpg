# 심연의 대장간: 저주받은 성검

저주받은 성검을 벼려 15개의 황폐한 세계를 베어 넘기는 **다크 판타지 강화 · 사냥 모바일 RPG**입니다.
원작 《전설의 대장장이: 종말의 성검 강화하기》의 강화 루프를 살리되, 분위기를 흑요석 · 진홍 · 황금 룬의
다크 판타지로 완전히 다시 지었습니다. 모든 캐릭터 · 몬스터 · 이름 · 일러스트는 이 게임을 위한 **오리지널** assets입니다.

- 세계 15개 · 원정 구역 180개 · 지배자 15종
- 전체 화면 **보스 아레나** + 하단 **스킬 & 액션 컨트롤 바**
- 캔버스 파티클(불씨 · 재 · 안개 · 룬 광휘)과 지배자 아레나 번개 연출

---

## 1. 바로 실행하기 (PWA)

1. `www/` 폴더를 정적 호스팅(GitHub Pages, Netlify, Vercel, 로컬 웹 서버)에 올립니다.
2. 스마트폰 브라우저(Chrome / Safari)로 접속합니다.
3. 메뉴에서 **홈 화면에 추가 / 앱 설치**를 선택하면 전체 화면 앱으로 실행됩니다.
4. `sw.js`가 앱 파일을 캐시하므로 한 번 열면 **오프라인**에서도 실행됩니다.

> 로컬에서 확인할 때는 `www` 폴더에서 `python3 -m http.server 8000` 같은 명령으로 서버를 띄우면 됩니다.

## 2. Android 앱으로 빌드하기 (Capacitor)

```bash
npm install
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
# 결과: android/app/build/outputs/apk/debug/app-debug.apk
```

또는 이 저장소에 포함된 GitHub Actions 워크플로(`.github/workflows/build-apk.yml`)가
push 될 때마다 자동으로 debug APK를 빌드하고 `mongle-forge-apk` 아티팩트로 올립니다.

```bash
gh run list --workflow=build-apk.yml
gh run download <run-id> -n mongle-forge-apk -D ./apk
```

## 3. 게임 내용

### ⚒ 대장간 (강화)
- 검 **+0 → +25**, 26단계 이름과 7가지 등급(녹슨 철 · 잿빛 강철 · 서리 · 비전 · 잿불 · 혈월 · 성광).
- 강화 확률: 성공 / 유지 / 하락 / **파괴**. +5강부터 하락, +10강부터 파괴.
- **장인의 원한(천장)**: 실패할수록 차오르고 100%가 되면 다음 강화는 확정 성공.
- **봉인 부적**: +10강부터 골드를 더 내고 켜서 파괴를 한 번 막습니다.
- **성급 표시**: +5 / +10 / +15 / +20 / +25 별.
- 매각, 잿가루 광맥 채굴, 잿불 용광로, 4종 연구(숙련도 · 원한 · 용광로 · 곡괭이).

### ⚔ 사냥 · 보스 아레나
- **세계 1~15**, 총 **180개 구역**. 1~9세계는 `X-1 ~ X-10`, 10~15세계는 `X-1 ~ X-15`.
- 마지막 구역(`X-10`, `X-15`)은 **지배자의 방**입니다.
- 구역에 도전하면 **전체 화면 전투 아레나**가 열리고, 하단 내비게이션과 대장간/유물/도감 패널은 숨겨집니다.
- 하단 **스킬 & 액션 컨트롤 바**: `공격` 버튼(수동 타격), 기술 1·2·3(쿨다운 표시), 그리고 지배자 패턴 대응용 `방어 / 회피 / 카운터` 버튼.
- 좌측 상단 `퇴각` 버튼으로 언제든 대장간 · 사냥 선택 화면으로 돌아갑니다.
- 승리/패배 결과 창은 전투 화면 위에 그대로 뜹니다.
- 실시간 사이드뷰 전투: 자동 공격 + **몬스터 직접 타격** + 3종 액티브 기술(쿨다운).
- **치명타**, 콤보, 데미지 팝업(CRIT), 골드 드롭, 각성 연출.
- 웨이브마다 체력 회복, 정복 시 다음 구역 해금. 지나온 구역은 **언제든 재입장(파밍)** 가능.
- 설정에서 **다음 구역 자동 진군** / **같은 곳 반복 사냥**을 선택할 수 있습니다.

### 👁 지배자 패턴
지배자는 HP 50% 이하에서 **격노**하며, 주기적으로 패턴을 사용합니다.
- **강타**: 2.4초 경고 → `방어`로 피해 75% 감소 (성공 시 반격)
- **돌진**: 1.9초 경고 → `회피`로 피해 완전 회피 (성공 시 반격)
- **보호막**: 5초간 피해 72% 감소 → `카운터`로 보호막 파괴 + 260% 피해 + 2초 스턴
- 지배자는 **유물 파편 · 룬석 · 골드**를 대량으로 떨어뜨립니다(첫 정복 보너스 추가).

### 🔮 유물
지배자가 주는 **유물 파편**으로 6종 유물을 각성 · 강화합니다(영구 효과).
- 전몰자의 군기(공격력), 저주받은 네잎(치명타), 해골 열쇠(골드), 핏빛 성심(체력),
  저주받은 모루(강화 성공률), 월식 모래시계(오프라인 보상).

### 📖 도감 · 업적 · 성장
- **도감 45종** (15세계 × 몬스터 2 + 지배자 1). 처음 베면 등록되고 보상을 줍니다.
- **업적 23종**: 강화 · 사냥 · 지배자 · 유물 · 서약자 레벨 · 도감 · 골드. 보상 수령 가능.
- 서약자 **Lv.1 ~ 99**, 경험치 · 공격력 · 체력 · 치명타 성장.
- 기술 3종은 서약자 Lv.1 / 3 / 5에 각성되고 룬석으로 레벨업합니다.

### 🌑 오프라인 보상
앱을 닫아둔 시간에 따라 골드 · 룬석 · 경험치가 쌓입니다(기본 최대 8시간, 모래시계 유물로 연장).

## 4. 저장

- 모든 진행은 **`localStorage`에 자동 저장**됩니다: 강화 · 사냥 · 유물 · 업적 · 설정 변경 시, 5초마다,
  화면을 벗어날 때(`visibilitychange`), 앱을 닫을 때(`pagehide`, `beforeunload`).
- 저장 키: `mongle_forge_save_v2` (이전 버전 저장과 호환)
- 설정 탭에서 **내보내기(JSON 복사/파일 저장)** 와 **불러오기(붙여넣기/파일 선택)** 를 지원합니다.

## 5. 파일 구조

```
www/
  index.html            게임 화면 (전체 화면 배틀 아레나 · 스킬 컨트롤 바 포함)
  assets/               고해상도 다크 판타지 일러스트 (아레나/대장간/영웅/지배자/성검)
  css/style.css         흑요석 다크 판타지 테마 · 세로/가로 모드 레이아웃
  js/data.js            검 26단계 · 세계 15개 · 몬스터 45종 · 패턴 · 유물 · 업적 데이터
  js/sprites.js         오리지널 SVG 스프라이트 (발광 눈빛 · 저주받은 검)
  js/core.js            저장 · 계산 · 강화 · 전투 · 지배자 패턴 · 오프라인 로직
  js/vfx.js             캔버스 연출 (불씨 · 안개 · 룬 · 번개)
  js/ui.js              렌더링 · 전투 컨트롤 · 연출 · 사운드 · 모달 · 자동 저장
  icons/                PWA 아이콘 (192/512/maskable)
  manifest.json         PWA 매니페스트
  sw.js                 오프라인 캐시 서비스 워커
android_capacitor_template/capacitor.config.json
.github/workflows/build-apk.yml
README.md
```

## 6. 조작

- 하단 내비게이션: **사냥 / 대장간 / 유물 / 도감·설정**
- 사냥: 구역 선택 → 전투 화면에서 하단 `공격` 버튼 또는 몬스터를 직접 탭.
- 지배자 경고가 뜨면 컨트롤 바의 `방어 / 회피 / 카운터` 중 맞는 것을 누릅니다.
- 가로 모드에서도 아레나는 전체 화면이고, 컨트롤 바는 하단에 컴팩트하게 붙습니다.
