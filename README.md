# 몽글 대장간: 별빛 성검 키우기

아기자기한 **강화 · 사냥 · 유물 수집** 모바일 RPG입니다.
원작 《전설의 대장장이: 종말의 성검 강화하기》의 강화 루프를 그대로 살리고,
15개 세계 × 180개 스테이지의 사냥과 보스 패턴, 유물, 도감, 업적, 오프라인 보상을 더했습니다.
모든 캐릭터·몬스터·이름·일러스트는 이 게임을 위해 새로 만든 **오리지널** assets입니다.

---

## 1. 바로 실행하기 (PWA)

1. `www/` 폴더를 정적 호스팅(GitHub Pages, Netlify, Vercel, 로컬 웹 서버)에 올립니다.
2. 스마트폰 브라우저(Chrome / Safari)로 접속합니다.
3. 메뉴에서 **홈 화면에 추가 / 앱 설치**를 선택하면 전체 화면 앱으로 실행됩니다.
4. `sw.js`가 앱 파일을 캐시하므로 한 번 열면 **오프라인**에서도 실행됩니다.

> 로컬에서 확인할 때는 `www` 폴더에서 `python3 -m http.server 8000` 같은 명령으로 서버를 띄우면 됩니다.
> (`file://`로 열어도 게임은 실행되지만, 서비스 워커와 앱 설치는 http/https에서만 동작합니다.)

## 2. Android 앱으로 빌드하기 (Capacitor)

```bash
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
cp android_capacitor_template/capacitor.config.json ./
npx cap add android
npx cap copy
npx cap open android
```

Android Studio에서 서명 후 APK/AAB로 빌드하면 됩니다. `webDir`는 `www`입니다.

## 3. 게임 내용

### ⚒️ 대장간 (강화)
- 무기 **+0 → +25**, 26단계 이름과 7가지 등급(나무·민트·하늘·라벤더·노을·벚꽃·성광).
- 강화 확률: 성공 / 유지 / 하락 / **파괴**. +5강부터 하락, +10강부터 파괴.
- **장인의 기운(천장)**: 실패할수록 차오르고 100%가 되면 다음 강화는 확정 성공.
- **파괴 방지권**: +10강부터 골드를 더 내고 켤 수 있어 파괴를 한 번 막습니다.
- **성급 표시**: +5 / +10 / +15 / +20 / +25 별.
- 판매, 광맥 채굴, 자동 용광로, 4종 연구(숙련도·영감·용광로·곡괭이).

### ⚔️ 사냥
- **세계 1~15**, 총 **180개 스테이지**. 1~9세계는 `X-1 ~ X-10`, 10~15세계는 `X-1 ~ X-15`.
- 마지막 스테이지(`X-10`, `X-15`)는 **보스방**입니다.
- 실시간 사이드뷰 전투: 자동 공격 + **몬스터 톡톡 탭 공격** + 3종 액티브 스킬(쿨다운).
- **치명타**, 콤보, 데미지 팝업(CRIT!), 코인 드롭, 레벨업 연출.
- 웨이브마다 체력 회복, 클리어 시 다음 스테이지 해금. 지나온 스테이지는 **언제든 재입장(파밍)** 가능.
- 설정에서 **다음 사냥터 자동 진행** / **같은 곳 반복 사냥**을 선택할 수 있습니다.

### 👑 보스 패턴
보스방 보스는 HP 50% 이하에서 **격노**하며, 주기적으로 패턴을 사용합니다.
- **강타**: 2.4초 경고 → `🛡️ 방어`로 피해 75% 감소 (성공 시 반격)
- **돌진**: 1.9초 경고 → `🌀 회피`로 피해 완전 회피 (성공 시 반격)
- **보호막**: 5초간 피해 72% 감소 → `⚡ 카운터`로 보호막 파괴 + 260% 피해 + 2초 스턴
- 보스는 **유물 조각·강화석·골드**를 대량으로 떨어뜨립니다(첫 클리어 보너스 추가).

### 🔮 유물
보스가 주는 **유물 조각**으로 6종 유물을 해금·강화합니다(영구 효과).
- 용기의 깃발(공격력), 네잎 클로버(치명타), 황금 열쇠(골드), 하트 젤리(체력),
  대장장이의 모루(강화 성공률), 달빛 모래시계(오프라인 보상).

### 📖 도감 · 업적 · 성장
- **도감 45종** (15세계 × 몬스터 2 + 보스 1). 처음 잡으면 등록되고 보상을 줍니다.
- **업적 23종**: 강화·사냥·보스·유물·영웅 레벨·도감·골드. 보상 수령 가능.
- 영웅 **Lv.1 ~ 99**, 경험치·공격력·체력·치명타 성장.
- 스킬 3종은 영웅 Lv.1 / 3 / 5에 해금되고 강화석으로 레벨업합니다.

### 🌙 오프라인 보상
앱을 닫아둔 시간에 따라 골드·강화석·경험치가 쌓입니다(기본 최대 8시간, 모래시계 유물로 연장).
다시 열면 자동으로 받고 요약 창을 보여줍니다.

## 4. 저장

- 모든 진행은 **`localStorage`에 자동 저장**됩니다: 강화·사냥·유물·업적·설정 변경 시, 5초마다,
  화면을 벗어날 때(`visibilitychange`), 앱을 닫을 때(`pagehide`, `beforeunload`).
- 저장 키: `mongle_forge_save_v2`
- 설정 탭에서 **내보내기(JSON 복사/파일 저장)** 와 **불러오기(붙여넣기/파일 선택)** 를 지원합니다.
- 초기화는 설정 → 처음부터.

## 5. 파일 구조

```
www/
  index.html            게임 화면
  css/style.css         파스텔 테마 · 세로/가로 모드 레이아웃
  js/data.js            무기·세계·몬스터·보스 패턴·유물·업적 데이터
  js/sprites.js         오리지널 SVG 캐릭터/몬스터/성검 일러스트
  js/core.js            저장·계산·강화·전투·보스 패턴·오프라인 로직
  js/ui.js              렌더링·연출·사운드·모달·자동 저장
  icons/                PWA 아이콘 (192/512/maskable)
  manifest.json         PWA 매니페스트 (orientation: any)
  sw.js                 오프라인 캐시 서비스 워커
android_capacitor_template/capacitor.config.json
README.md
```

## 6. 조작

- 하단 내비게이션: **사냥 / 대장간 / 유물 / 도감·설정**
- 사냥: 사냥터 선택 → 몬스터를 **톡톡 탭**하면 즉시 공격, 스킬 버튼으로 액티브 스킬.
- 보스 경고가 뜨면 **방어 / 회피 / 카운터** 버튼을 누릅니다.
- 가로 모드에서는 전투 화면과 선택한 관리 패널(대장간·유물·도감)이 **나란히** 표시됩니다.
